# PopClip Extensions

Extensions for [PopClip](https://www.popclip.app/) by Adrian Ramon.

| Extension | What it does |
|---|---|
| [Number to Words](NumberToWords.popclipext/) | Spells out numbers and amounts (£, $, €) in British English words, on their own or inside a sentence. |
| [Number Formatter](NumberFormatter.popclipext/) | Adds thousands separators to numbers in your Mac's format or a chosen international style, and converts between styles. |
| [Superscript](Superscript.popclipext/) | Superscript and subscript anywhere you can type, with smart fixes for units and formulas (m3 → m³, CO2 → CO₂). |
| [Clean Spaces](CleanSpaces.popclipext/) | Tidies spacing in copied text: double spaces, non-breaking and invisible characters, trailing spaces and extra blank lines. |
| [Character Map](CharacterMap.popclipext/) | Shows selected text character by character as numbered, colour-coded tiles with NATO phonetic names, for reading aloud. |
